# Portfolio-Cl

This is a very simple porfolio that I developed using common lisp to have some fun.

It also has a very simple blog which functions in a simple way without having to use something like sqlite.

## how to Run

You will require to install [sbcl](https://www.sbcl.org/), and [qlot](https://github.com/fukamachi/qlot)

After that you can run it by just running the next command

```
qlot exec sbcl --script run.lisp
```

If you want to apply any change you are completely welcome to do it
